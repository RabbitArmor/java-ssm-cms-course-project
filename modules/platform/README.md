## 设计与验证记录

- 审计写入保存操作者、动作、对象、时间和结果。成功记录与业务变更同事务，失败记录可独立提交。日志保留操作者的 ID 快照，业务账号变更后仍能追溯。
- 审计查询按操作者、动作和 UTC 时间区间分页筛选。接口从身份模块提供的会话取得权限，要求 `audit.read`。
- 2026-11-26 使用 JDK 21、Maven 3.9.9 和隔离 MySQL 8.0.44。6 项测试通过，包括真实数据库连接、事务回滚、筛选区间，以及 HTTP 权限和参数校验。
- 在工作区和无构建产物的独立源码副本分别执行 `mvn clean verify`，两次均通过。产物为 `cms-app/target/cms.war`。
- 部署到独立 Tomcat 10.1.55 后，HTTP 存活和 MySQL 就绪均返回 200，匿名审计查询返回 401，非法页大小返回 400。停止临时 MySQL 后，HTTP 存活仍返回 200，MySQL 就绪返回 503。

## AI 辅助与复核

本轮使用 Codex 根据共享交接和课程指导书搭建工程、起草接口并生成测试。核对了远程 `main` 的基线、实验二 EMP 的依赖和容器版本，用本机 Maven、MySQL 和 Tomcat 验证实现。首次部署时 Tomcat 未自动发现 JDBC 驱动，显式配置 MySQL 驱动后复测通过。组员可用上面的部署步骤独立复跑，并在个人报告中补充手工核验记录。
