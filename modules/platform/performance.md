# 文章列表 SQL 对比

此项由 C、D 在文章列表实现后共同执行。把两版实现、可重放的虚构数据和运行结果附到对应 PR。

1. 记录测试分支、提交、MySQL 版本、SQL 数据量、页面大小和过滤参数。为文章准备不同的作者和类别，同时覆盖全员通报、定向通报和下架文章。
2. 用同一个读者会话、筛选条件和排序分别调用基线及优化版。预热后对同一页各执行三次，依次记录每次请求的 SQL 序列、语句条数、文章 ID 顺序和分页总数。
3. SQL 计数包含分页 COUNT、主查询以及作者和分类补全查询。从 MyBatis 的测试日志提取单次请求的语句，用请求边界避免混入其他流量。若基线逐行查询作者或分类，优化版可按页批量查询或使用联表，并保留所有业务筛选条件。
4. 对比返回内容及访问范围，再报告 SQL 数量。记录查询结构变化，保留原始日志摘录。测试日志只使用虚构数据。

当前分支还没有文章列表和文章样本数据，实际 SQL 数量待联调。
